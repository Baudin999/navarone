# Split complexity is a signal: a method whose cyclomatic with its helpers inlined passes 10 sends the builder to look

## Why
Splitting a method so each piece passes the limit hides the complexity instead of removing it; the split is measured as if inlined, so the trick gains nothing.

## Edges
- part-of -> process
- refines -> cyclomatic
