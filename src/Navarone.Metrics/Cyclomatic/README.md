# Cyclomatic

Subject: method. Default limit: 10. A finding is raised only above the limit.

Cyclomatic complexity, from McCabe 1976. Edges minus nodes plus two; for structured code, the decisions in a method plus one. Every branch, loop, case, catch, conditional, every short circuit `&&` and `||`, every `when` guard, every subpattern that tests a value and every null check counts, because McCabe counts predicates, whatever syntax writes them. A call and a `!` add nothing of their own: the decision is the test of their result.

It counts each `Branch`, `SwitchCase`, `Guard`, `PatternTest`, `Loop`, `Catch`, `Conditional`, `LogicalAnd`, `LogicalOr` and `NullCheck` fact. A plain `Else`, a `Switch` as a whole and a `Jump` add no path of their own. The C# provider maps `?.`, `??` and `??=` to `NullCheck`, as Microsoft's code metrics count them, so rewriting `if (x == null) x = y;` as `x ??= y;` keeps the score. Each case and each arm of a switch expression but a catch-all, each catch and each pattern `and` and `or` count. A `when` guard is a `Guard`, which counts: its case, arm or catch can fail after its pattern matched. A subpattern that tests a value, `{ IsConst: false }`, `{ ContainingSymbol: IMethodSymbol c }` or `(> 0, null)`, is a `PatternTest` in an `is` pattern as in a switch; a bare binding, `var n` or `_`, is none. A list pattern is a `PatternTest` for its length, a constant or a range, unless a lone slice such as `[..]` takes any length, and each element that tests a value is one more, so `['a', _, ..]` adds 2. A `not` in a pattern adds nothing, like a `!`: it flips a test that is already counted. So `IParameterSymbol { ContainingSymbol: IMethodSymbol c } p when IsPrimary(c) && !InInitializer(node)` adds 4, what the same tests cost written as an if. A `default` label and a catch-all, a case or arm whose pattern is a discard or a var pattern such as `_ when c` or `case var x`, are `Default` facts, which do not count; a when on a catch-all counts as its own `Guard`. split-complexity sums these same values. The control flow of a lambda or a local function counts in the method it is written in.

Reads `MethodFacts.ControlFlow`. The value is computed from the method's evidence, `CyclomaticMetric.EvidenceOf`, which every finding carries: the method's code, the base of 1 and a proof tree with one item per fact, each with its span, its construct, what it adds and why, and the facts that are part of it as its parts. The value is the base plus every adds in the tree, so the proof is the count and the two cannot drift. A fact that does not count shows with adds 0 and its reason. McCabe calls a limit of ten reasonable, but not magical. The finding asks why the method has this many paths, and a flat switch is a valid answer.
