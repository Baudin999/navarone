# Navarone.Tests

xUnit v3 tests for the engine, the metrics, the classifiers, the C# provider and the CLI. Run them with `dotnet test` at the repo root; `global.json` selects Microsoft.Testing.Platform, and the run exits non-zero when a test fails.

A metric's limit tests feed it hand built facts. Its counting tests feed small C# snippets through the provider's fact extractor in memory, `Support/CSharpSnippet`, so each number is checked against code a reader can count by hand. The cyclomatic tests also read all of Navarone's own source this way and check that every proof tree holds each control flow fact once, that the base plus every adds is the reported value, and that every span's text is the file's text at its lines and columns. The provider's tests feed it C# and check the facts it hands over. The engine's tests use `Support/FakeProvider`, which hands over per path the hand built facts of `Support/FakeFacts`, a temporary repo root for `reasons.json`, `Support/TempRepo`, and a temporary data folder for the event log and code store, `Support/TempEvents`, so no test writes to the user's own. The clash tests read the user's answers from a temporary folder in place of brain's, and the tests of a refusal read the rules of a temporary NAVARONE.md, `Support/TempTaste`, in place of the user's.

The engine's and the CLI's tests wire the real deterministic classifiers through `Wiring`, with the fake provider in place of the C# one. The CLI is referenced through `InternalsVisibleTo`, for `Wiring`, `Commands` and `FileLocations`.

In a git repo with a commit the engine keeps the facts in its cache, keyed by the files, so a test there that changes what the fake provider hands over changes a file too, as a real change of the code would. `FactsCacheTests` changes the fake facts without one on purpose: facts that stay the same came from the cache.

Every engine and CLI test gets brain's answers and the global NAVARONE.md at paths inside its `TempEvents` folder, through `TempEvents.Isolate`, so none reads the user's ~/.claude or brain's cache. No test sets an environment variable of the test process: `DataHomeTests` runs the built navarone as a child process with an environment of its own to pin where its event log lands. `TempRepo` runs git with no global or system config, and every `git init` in a test names its branch with `-b`. `CSharpProviderTests` also loads a real solution from disk through MSBuild, to pin that the provider honours the ignores in navarone.json.
